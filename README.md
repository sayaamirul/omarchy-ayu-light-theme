# Omarchy Ayu Light Theme

An [Ayu Light](https://github.com/dempfi/ayu)-inspired theme for [Omarchy](https://omarchy.org/).

## Install

```bash
omarchy theme install https://github.com/sayaamirul/omarchy-ayu-light-theme.git
```

Or manually:

```bash
git clone https://github.com/sayaamirul/omarchy-ayu-light-theme.git ~/.config/omarchy/themes/ayu-light
omarchy theme set ayu-light
```

## Includes

- Full color palette (`colors.toml`) matching the Ayu Light scheme
- Backgrounds (including a Dragon Ball Z wallpaper)
- Neovim colorscheme config (ayu-vim light)
- VS Code theme mapping (teabyii.ayu)
- Chromium tint and Yaru-yellow icons
